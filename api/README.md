## Description

Backend API for Job Assistance — a [Nest](https://github.com/nestjs/nest) app on the Fastify adapter, backed by Postgres via TypeORM.

- **Swagger UI** is served at the root path, `/` (raw OpenAPI JSON at `/-json`).
- **Entities** live under `src/entities/<name>/`, each with an `.entity.ts` (TypeORM model), `.repository.ts` (the only file that talks to TypeORM's `Repository<T>`), `.service.ts` (business logic, throws `NotFoundException` etc.), `.controller.ts` (REST routes + Swagger decorators), a `.module.ts`, and a `dto/` folder. `src/entities/example/` is a dummy entity — copy its shape for real ones.
- **Database config** comes from env vars (see `.env.example`): `DB_HOST`, `DB_PORT`, `DB_USERNAME`, `DB_PASSWORD`, `DB_NAME`. `synchronize` is on outside of `NODE_ENV=production`, so tables auto-create/update from entities in dev — swap to migrations before this holds real data.

Copy `.env.example` to `.env` and point it at a running Postgres instance before starting the app.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
